# Choose the files to synchronize

**Choose files** lists the source files of the Overleaf project, followed by local text files that are not on Overleaf yet.

- The first time, every source file on Overleaf starts ticked, the main document first.
- A local file that is not on Overleaf yet is created there at Send.
- Pictures and PDF figures (PNG, JPG, PDF) come along by content (`turnleaf.syncPictures`).

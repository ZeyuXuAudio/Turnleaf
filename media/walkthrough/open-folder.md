# Open the folder of your paper

Turnleaf links one local folder to one Overleaf project.

- Use the folder that holds your `.tex` and `.bib` files, or an empty folder to start from the Overleaf version.
- Trust the folder when the editor asks: Turnleaf does not run in Restricted Mode.
- Git is not needed. An existing Git repository works as an ordinary folder; Turnleaf never commits, branches or stashes.

Turnleaf keeps its own state in a `.turnleaf/` folder inside your folder.

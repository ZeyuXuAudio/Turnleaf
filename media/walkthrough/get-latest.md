# Get the latest version

**Get latest** fetches the current Overleaf text and prepares a three-way merge with your saved files.

- Click a file name to see **Local now → After merge**.
- **Apply (n)** changes your files, where n is the number of updates; until then nothing local changes. On the first sync with nothing to bring in, the button reads **Use this baseline**.
- On the first sync, files that differ need a choice: **Use Overleaf version**, **Keep my version** or **Merge manually**.

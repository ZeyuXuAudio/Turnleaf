# Enable sending, then Send

Turnleaf writes nothing to Overleaf until you enable sending for the project (open the sidebar, select **Setup**, then choose **Enable sending**).

The **outgoing summary** at the top of the sidebar always shows what the next Send writes: each file with its added and removed lines, and each comment change.

- **Send** re-reads Overleaf and sends only when the result still equals the summary.
- **Undo this send** in Sync history takes a send back.
